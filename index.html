Tentang Saya

Mengenal latar belakang dan pendekatan rekayasa perangkat lunak saya

Saya adalah lulusan D3 Teknik Informatika yang berfokus pada pengembangan aplikasi fullstack dan integrasi kecerdasan buatan (AI), dengan ketertarikan mendalam pada arsitektur backend. Selama masa studi dan pengerjaan berbagai proyek, saya terbiasa membangun sistem berbasis web dan mobile yang fungsional—mulai dari perancangan arsitektur database relasional (PostgreSQL, MySQL, Oracle Database), pembuatan REST API yang aman menggunakan Laravel dan Python, hingga integrasi antarmuka pengguna dengan React dan Flutter.

Saya antusias memecahkan masalah seputar optimasi alur data, otomatisasi proses bisnis—seperti algoritma pencocokan peran dan peringkas dokumen cerdas berbasis LLM—serta memastikan aplikasi siap dideploy menggunakan container Docker. Pendekatan saya berpusat pada penulisan kode yang terstruktur, integrasi sistem yang efisien, dan penerapan teknologi yang tepat guna untuk memberikan solusi nyata bagi pengguna.

Featured Project Web Application & Backend Core

ProjectPals – Platform Pembentukan Tim Proyek

Platform berbasis web untuk mengotomasi pembentukan tim proyek secara kolaboratif menggunakan algoritma pencocokan peran dan keahlian anggota.

Masalah

Pembagian tim kerja manual sering kali tidak seimbang dalam distribusi peran dan keahlian, serta memerlukan koordinasi room dan feedback yang rumit.

Solusi

Membangun sistem web dengan algoritma matching otomatis, standardisasi role anggota, pelacakan target bersama, dan evaluasi tim berbasis peer feedback.

Fitur Utama

  • Manajemen room dan sistem join via kode akses
  • Algoritma pembentukan tim otomatis berdasarkan profil
  • Layanan normalisasi role anggota untuk akurasi matching
  • Target tracking dan sistem evaluasi peer feedback
  • Panel admin untuk manajemen data

Peran & Kontribusi Saya

  • Merancang arsitektur backend dengan Laravel 13 dan Oracle Database
  • Mengembangkan algoritma matching tim dan service normalisasi role
  • Membangun antarmuka web interaktif menggunakan React, TypeScript, dan TanStack Query
  • Mengonfigurasi Docker dan pipeline CI/CD untuk otomatisasi deployment

Teknologi yang Digunakan

Laravel 13 Oracle Database React Js TypeScript TanStack Query Docker CI/CD

AI & Mobile Integration

Leksika – Asisten Belajar Berbasis AI

Aplikasi asisten belajar berbasis mobile yang memanfaatkan LLM untuk merangkum dokumen dan membuat bahan evaluasi interaktif secara otomatis.

Masalah

Pelajar sering kesulitan menyerap poin penting dari materi bacaan berukuran besar dan membutuhkan metode belajar aktif yang efisien.

Solusi

Mengintegrasikan model Groq AI (Llama 3.1) ke dalam backend Laravel untuk ekstraksi materi dokumen menjadi ringkasan, kuis, dan flashcard interaktif di Flutter.

Fitur Utama

  • Unggah dokumen (format PDF, DOCX, TXT)
  • Rangkuman materi otomatis berbasis Groq AI (Llama 3.1)
  • Pembuat kuis interaktif dan flashcard otomatis
  • Autentikasi lengkap: Register, Login, OTP Email, Google OAuth, Reset Password
  • Sistem streak harian dan notifikasi push via FCM

Peran & Kontribusi Saya

  • Mengembangkan REST API autentikasi (OTP, Google Login) dan endpoint profil pada Laravel 12
  • Mengintegrasikan pipeline Groq AI untuk pemrosesan teks dokumen
  • Menghubungkan seluruh REST API ke antarmuka aplikasi Flutter
  • Menyiapkan konfigurasi Docker dan deployment backend ke cloud (Railway/Render)

Teknologi yang Digunakan

Laravel 12 PostgreSQL Flutter Groq AI (Llama 3.1) Docker FCM Railway / Render

Mobile Application

ProjectPals Mobile – Klien Aplikasi Mobile

Klien mobile multi-platform untuk platform ProjectPals yang memungkinkan akses pemantauan tim, room, dan target proyek secara fleksibel.

Masalah

Kebutuhan anggota tim untuk menerima pembaruan proyek dan mengisi feedback secara instan saat tidak berada di depan komputer.

Solusi

Membangun aplikasi mobile berbasis Flutter yang terintegrasi penuh ke backend REST API Laravel yang sama dengan versi web.

Fitur Utama

  • Autentikasi pengguna secara mobile
  • Manajemen room dan pantauan pembagian tim
  • Monitoring target dan progres kerja
  • Input feedback antar-anggota tim
  • Push notification real-time via Firebase Cloud Messaging

Peran & Kontribusi Saya

  • Mengembangkan antarmuka aplikasi mobile dengan Flutter dan Dart
  • Mengintegrasikan endpoint backend Laravel (auth, room, tim, target, feedback, token FCM)
  • Menguji alur pertukaran data dan error handling REST API pada perangkat mobile

Teknologi yang Digunakan

Flutter Dart Laravel REST API Firebase Cloud Messaging
